🧮

คิด VAT 7% อัตโนมัติ

เปิดเป็นค่าเริ่มต้น คำนวณยอดรวม ส่วนลด และภาษีให้แม่นยำ — สั่ง “ไม่คิด VAT” ได้เมื่อต้องการ

🔤

บาทถ้วนอัตโนมัติ

แปลงยอดรวมเป็นตัวอักษรไทยด้วยสคริปต์ baht_text.py อิงมาตรฐาน Excel BAHTTEXT ไม่ต้องเดาเอง

🖨️

HTML → PDF (A4)

ได้ไฟล์ HTML ที่จัดหน้าสวยงาม เปิดในเบราว์เซอร์แล้วกด Save as PDF ขนาด A4 ได้ทันที

🏢

ข้อมูล BoomBigNose ตั้งต้น

ชื่อ อีเมล และเว็บไซต์ผู้ขายใส่ให้แล้ว เหลือเพียงเลขภาษี/ที่อยู่/เบอร์ ที่กรอกเองก่อนใช้จริง

🛡️

โหมด DRAFT

ทุกใบเป็น “ร่าง ยังไม่ได้อนุมัติ” จนกว่าจะยืนยัน ไม่ส่งออกภายนอกเองโดยพลการ

💬

ถาม-ตอบทีละขั้น

ข้อมูลไม่ครบ? ปลั๊กอินจะถามชื่อลูกค้า รายการ และราคาทีละขั้น ก่อนสร้างเอกสารให้

ติดตั้งใน 2 บรรทัด

เปิด Claude Code แล้วพิมพ์ตามนี้

ติดตั้งจาก GitHub ได้ทันที — repo เผยแพร่แล้วที่ Boom-Vitt/boombignose-plugins

1

เพิ่ม marketplace

> /plugin marketplace add Boom-Vitt/boombignose-plugins

ดึงรายการปลั๊กอินทั้งหมดของ BoomBigNose เข้ามาในเครื่อง

2

ติดตั้งปลั๊กอิน

> /plugin install thai-quotation@boombignose-plugins

หลัง @ คือชื่อ marketplace ไม่ใช่ path ของ repo

💡 ติดตั้งเสร็จเรียกใช้ได้เลยด้วย /thai-quotation:quote หรือพิมพ์เป็นภาษาธรรมชาติ เช่น “ออกใบเสนอราคาให้ลูกค้า…” — แล้ว skill จะทำงานเอง
