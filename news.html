Siri ยอมรับ Gemini เป็น "สมอง" — WWDC 2026 ครั้งสุดท้ายของ Tim Cook

Apple ประกาศ WWDC 2026 อย่างเป็นทางการ: Siri ใหม่รัน Google Gemini ภายใต้ดีลมูลค่าราว 1 พันล้านดอลลาร์ต่อปี ระบบ routing 3 ชั้น — งานง่ายประมวลผลในเครื่อง, งานกลางไปที่ Private Cloud Compute, งานหนักส่งต่อ Google Cloud บน GPU รุ่น Blackwell B200

พร้อมกันนี้ Apple เปิด multi-AI Extensions ให้ Claude ขึ้นเป็นตัวเลือก AI บน iPhone ได้เป็นครั้งแรก และยังเปิดตัว iOS 27 พร้อมฟีเจอร์ใหม่อีกเพียบ — นี่เป็น WWDC สุดท้ายของ Tim Cook ก่อนส่งไม้ต่อให้ John Ternus ในวันที่ 1 กันยายน

Microsoft ปลดแอก OpenAI — เปิดตัว MAI-Thinking-1 โมเดล reasoning ฝีมือตัวเอง

งาน Build 2026 Microsoft เปิดตัว MAI-Thinking-1 พร้อมอีก 6 โมเดลในตระกูล MAI — ทั้งหมดเทรนจากศูนย์โดยไม่ดึงข้อมูลจาก OpenAI แม้แต่นิดเดียว เจตนาชัด: ลดการพึ่งพา OpenAI และควบคุม cost ให้ developer ได้มากขึ้น

MAI-Thinking-1 ขนาด 35B active params (MoE) ทำ SWE-Bench Pro ได้ 53% เทียบชั้น Claude Opus 4.6 ในงานเขียนโค้ด ขณะนี้เปิดให้ใช้งาน private preview ผ่าน Microsoft Foundry

NVIDIA เปิดตัว Nemotron 3 Ultra — open-weights 550B params เร็ว 300+ tokens/วิ

ที่งาน Computex 2026 NVIDIA ประกาศ Nemotron 3 Ultra โมเดล open-weights ขนาด 550B parameters (แต่ active จริงแค่ 55B แบบ MoE) ใช้สถาปัตยกรรม Mamba-Transformer ไฮบริด ทำความเร็วได้ 300+ tokens/วินาที context window 1M tokens

คะแนน AI Intelligence Index ฝั่งสหรัฐฯ สูงสุดในบรรดา open-weight model ทั้งหมด — แม้ยังตามจีน (Kimi K2.6) อยู่บ้าง ออกให้ใช้งานแล้วบน HuggingFace, OpenRouter และ NIM ตั้งแต่วันที่ 4 มิ.ย.

Anthropic ส่ง Claude Mythos เข้าปกป้องโครงสร้างพื้นฐานสำคัญ 15+ ประเทศ

Anthropic ประกาศขยาย Project Glasswing — โครงการร่วมอุตสาหกรรมที่ใช้ Claude Mythos ในการค้นหาและแก้ไขช่องโหว่ซอฟต์แวร์ระดับวิกฤต ไปสู่ 150+ organizations ใน 15+ ประเทศ

เป้าหมายหลักคือโครงสร้างพื้นฐานด้านพลังงาน น้ำ และการเงิน นับเป็นก้าวใหญ่ของการนำ AI ไปใช้ป้องกันระบบสำคัญของชาติ แทนที่จะรอ patch แบบเดิม

AI Model Enterprise MindStudio · มิ.ย. 2569

Claude Opus 4.8 มาแล้ว — context 1M tokens + Managed Agents ทำงานในองค์กรได้เต็มรูปแบบ

Anthropic ขยาย Claude Opus 4.8 (ออกเมื่อ 28 พ.ค.) สู่วงกว้างในเดือนมิ.ย. นี่คือโมเดลที่ดีที่สุดในตระกูล Claude สำหรับงาน reasoning และ agentic coding ที่ซับซ้อน พร้อม context window เพิ่มเป็น 1M tokens เป็นค่าเริ่มต้น

ของใหม่ที่น่าสนใจ: Claude Managed Agents สามารถรันใน sandbox ขององค์กรและเชื่อมต่อ private MCP servers ได้เลย ข้อมูลไม่หลุดออกไปข้างนอก — ส่วน Claude Opus 4.1 จะ deprecated วันที่ 5 สิงหาคม 2026
