Anthropic ยื่นไฟล์ IPO เงียบ ๆ หลังปิดดีล Series H $65B — มูลค่าทะลุ $965B แซง OpenAI แล้ว

Anthropic เพิ่งปิดรอบระดมทุน Series H มูลค่า $65 พันล้านดอลลาร์ นำโดย Altimeter Capital, Sequoia Capital และ Dragoneer ทำให้บริษัทมีมูลค่าถึง $965 พันล้านดอลลาร์ — แซงหน้า OpenAI เป็นครั้งแรกในประวัติศาสตร์ พร้อมกันนั้นก็ยื่นไฟล์ S-1 กับ SEC แบบ confidential เพื่อเตรียม IPO ที่คาดว่าจะเกิดขึ้นช่วงปลายปี 2026 ถ้า Anthropic ออก IPO สำเร็จ revenue run rate ที่ $47B ต่อปีทำให้นี่คือหนึ่งในดีลเทคที่ใหญ่ที่สุดที่ Wall Street เคยเห็น

ผลิตภัณฑ์ · OpenAI OpenAI Blog

ChatGPT จำดีขึ้นจริง ๆ แล้ว — OpenAI อัปเกรด Memory ด้วย "Dreaming V3"

OpenAI เปิดตัว Dreaming V3 เมื่อ 4 มิ.ย. ระบบ memory ใหม่ที่ฉลาดขึ้นมาก จำได้ว่าคุณไปสิงคโปร์เดือนก่อน แล้วอัปเดตตัวเองให้รู้ว่าตอนนี้คุณกลับมาแล้ว แทนที่จะค้างข้อมูลเก่าแบบเดิม ๆ ระบบยังประหยัด compute ลงถึง 5 เท่า ทำให้ OpenAI มีแผนขยาย memory ไปยัง Free tier ด้วยในเร็ว ๆ นี้

สหรัฐฯ เปิดร่าง "Great American AI Act" — กฎหมาย AI ระดับชาติฉบับแรก 269 หน้า

ส.ส. Jay Obernolte และ Lori Trahan เปิดตัวร่างกฎหมาย AI สองพรรค 269 หน้าเมื่อ 4 มิ.ย. ครอบคลุมตั้งแต่การตรวจสอบความปลอดภัยบังคับทุก 6 เดือนสำหรับบริษัท AI รายใหญ่ ไปจนถึงการยับยั้งกฎหมายของรัฐต่าง ๆ เป็นเวลา 3 ปี บริษัทที่ฝ่าฝืนอาจโดนปรับสูงถึง $1M ต่อวัน — ถ้าผ่านสำเร็จนี่จะเป็น framework AI ระดับชาติฉบับแรกของสหรัฐฯ

โมเดลใหม่ · Microsoft Microsoft AI · GitHub

Microsoft ปล่อย MAI-Code-1-Flash — โมเดลโค้ดฝีมือตัวเองใน GitHub Copilot ไม่พึ่ง OpenAI

Microsoft เปิดตัว MAI-Code-1-Flash เมื่อ 2 มิ.ย. โมเดลโค้ดฝีมือ MS เองตัวแรก ฝึกด้วยข้อมูลที่ได้รับอนุญาตอย่างถูกต้อง ขนาด 137B param แต่ใช้แค่ 5B param จริง ๆ ตอนรัน ผลเทสเหนือกว่า Claude Haiku 4.5 ในหลาย benchmark ด้านโค้ด พร้อมให้ใช้แล้วใน GitHub Copilot ทุก tier ตั้งแต่ Free ถึง Max
