ผู้ใช้ต้องการ **ออกใบเสนอราคาภาษาไทย** ให้ใช้ skill `quotation` เป็นตัวจัดการ flow ทั้งหมด

ข้อมูลตั้งต้นจากผู้ใช้ (ถ้ามี): $ARGUMENTS

ขั้นตอน:
1. ใช้ skill `quotation` (อ่าน `skills/quotation/SKILL.md`) เป็นแหล่งตรรกะหลัก
2. ตีความ `$ARGUMENTS` เป็นข้อมูลตั้งต้น (ชื่อลูกค้า / รายการสินค้า-บริการ / จำนวน / ราคา ฯลฯ) เท่าที่อ่านได้
3. ถ้าข้อมูลที่จำเป็นไม่ครบ (เช่น ขาดชื่อลูกค้า หรือยังไม่มีรายการสินค้า/ราคา) ให้ **ถามผู้ใช้ทีละขั้น** ตามรายการ "ข้อมูลที่ต้องเก็บ" ใน SKILL.md
4. ทำตาม flow ใน SKILL.md ให้ครบ: คำนวณยอด → รัน `baht_text.py` เพื่อได้บาทถ้วน → แทน token ใน `assets/template.html` → เขียนไฟล์ `ใบเสนอราคา-{DOC_NO}.html` ที่ working directory ของผู้ใช้
5. ปิดท้ายด้วยวิธี Save เป็น PDF และแจ้งสถานะ **DRAFT — ยังไม่ได้อนุมัติ**

(ตรรกะรายละเอียดทั้งหมดอยู่ใน SKILL.md — ไม่ต้องทำซ้ำที่นี่)
