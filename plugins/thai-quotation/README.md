# thai-quotation — ปลั๊กอินออกใบเสนอราคาภาษาไทย

ปลั๊กอิน Claude Code สำหรับ **สร้างใบเสนอราคา (Quotation) ภาษาไทย** ให้ลูกค้าอย่างรวดเร็ว ผลลัพธ์เป็นไฟล์ HTML ที่ออกแบบมาให้พิมพ์เป็น PDF ขนาด A4 ได้สวยงาม พร้อมคิด VAT 7% และแปลงยอดรวมเป็นตัวอักษรไทย (บาทถ้วน) ให้อัตโนมัติ มีข้อมูลผู้ขาย **BoomBigNose** ตั้งต้นให้แล้ว

## ทำอะไรได้บ้าง
- 📄 **ใบเสนอราคาภาษาไทย** — เอกสารทางการ อ่านง่าย น่าเชื่อถือ พร้อมตารางรายการสินค้า/บริการ
- 🧮 **คิด VAT 7% อัตโนมัติ** — เปิดเป็นค่าเริ่มต้น (สั่ง "ไม่คิด VAT" ได้)
- 🔤 **บาทถ้วนอัตโนมัติ** — แปลงยอดรวมเป็นตัวอักษรไทยด้วยสคริปต์ `baht_text.py` (อิงมาตรฐาน Excel BAHTTEXT) ไม่เดาด้วยมือ
- 🖨️ **ส่งออก HTML → PDF** — เปิดในเบราว์เซอร์แล้ว Save as PDF ได้ทันที (A4)
- 🏢 **ข้อมูล BoomBigNose ตั้งต้น** — ชื่อ/อีเมล/เว็บไซต์ใส่ให้แล้ว (เลขภาษี/ที่อยู่/เบอร์ เป็น placeholder ให้กรอกเอง)
- 🛡️ **โหมด DRAFT** — ทุกใบเป็น "ร่าง ยังไม่ได้อนุมัติ" จนผู้ใช้ยืนยัน ไม่ส่งออกภายนอกเองโดยพลการ

## การติดตั้ง
ติดตั้งผ่าน marketplace `boombignose-plugins`:
```
/plugin install thai-quotation@boombignose-plugins
```

## วิธีใช้
ใช้ได้ 2 แบบ:

**1) สั่งด้วยภาษาธรรมชาติ** (skill จะ auto-trigger เอง)
> ออกใบเสนอราคาให้ลูกค้า บริษัท ABC จำกัด — ออกแบบโลโก้ 1 งาน ราคา 15,000 บาท

**2) ใช้ slash command**
```
/thai-quotation:quote บริษัท ABC จำกัด / ออกแบบโลโก้ 1 งาน / 15000
```
หรือเรียกเปล่า ๆ แล้วให้ถามทีละขั้น:
```
/thai-quotation:quote
```

ถ้าข้อมูลไม่ครบ (เช่น ขาดชื่อลูกค้า หรือรายการสินค้า/ราคา) ปลั๊กอินจะ **ถามทีละขั้น** ก่อนสร้างเอกสาร

## ตัวอย่างการใช้งาน
**ผู้ใช้:**
> ทำใบเสนอราคาให้ร้านกาแฟ Bean Dream — ทำเว็บไซต์ 1 ระบบ 45,000 บาท, ดูแลรายเดือน 3 เดือน เดือนละ 5,000 บาท คิด VAT ด้วย

**ปลั๊กอินจะ:**
1. คำนวณ: รายการที่ 1 = 45,000.00, รายการที่ 2 = 15,000.00 → รวม 60,000.00
2. VAT 7% = 4,200.00 → รวมทั้งสิ้น **64,200.00**
3. รัน `baht_text.py 64200` → "หกหมื่นสี่พันสองร้อยบาทถ้วน"
4. สร้างไฟล์ `ใบเสนอราคา-QT-2569-001.html` ที่โฟลเดอร์ปัจจุบัน
5. แจ้งวิธี Save เป็น PDF + สถานะ **DRAFT — ยังไม่ได้อนุมัติ**

จากนั้นเปิดไฟล์ในเบราว์เซอร์ → กด Print (Cmd/Ctrl+P) → Save as PDF (A4, เปิด Background graphics)

## โครงสร้างไฟล์ในปลั๊กอิน
```
thai-quotation/
├── .claude-plugin/plugin.json        manifest ของปลั๊กอิน
├── README.md                         ไฟล์นี้
├── commands/
│   └── quote.md                      slash command /thai-quotation:quote
└── skills/quotation/
    ├── SKILL.md                      ตรรกะหลัก (คำนวณ + flow สร้างเอกสาร)
    ├── assets/
    │   ├── template.html             เทมเพลตใบเสนอราคา (ต้นฉบับ — ไม่ถูกแก้)
    │   └── example.html              ตัวอย่างใบที่กรอกค่าแล้ว
    ├── scripts/
    │   └── baht_text.py              แปลงจำนวนเงินเป็นบาทถ้วน (Python 3, stdlib)
    └── references/
        └── baht-text.md              อธิบายกฎการอ่านบาทถ้วน
```

## ข้อกำหนด (Requirements)
- ต้องมี **Python 3** ในเครื่อง (ใช้ `python3` รัน `baht_text.py` — ใช้เฉพาะ standard library ไม่ต้องติดตั้งอะไรเพิ่ม)
- เบราว์เซอร์สำหรับเปิดไฟล์ HTML และ Save เป็น PDF
- ฟอนต์ไทย: เทมเพลตใช้ `Sarabun` (โหลดจาก Google Fonts เมื่อออนไลน์) และมี fallback `TH Sarabun New`, `Tahoma` เมื่อออฟไลน์

## หมายเหตุก่อนใช้งานจริง
- ⚠️ **กรอกข้อมูลผู้ขายจริงก่อนส่งลูกค้า:** เลขประจำตัวผู้เสียภาษี 13 หลัก, ที่อยู่บริษัท และเบอร์โทร **ไม่ได้ระบุไว้** จึงเป็น placeholder `[... — โปรดระบุ]` — ต้องแทนด้วยข้อมูลจริงก่อนนำไปใช้ ปลั๊กอินจะไม่แต่งตัวเลขเหล่านี้ขึ้นเอง
- ทุกใบที่สร้างเป็น **DRAFT — ยังไม่ได้อนุมัติ** จนกว่าผู้ใช้จะตรวจและยืนยัน
- ตรวจสอบยอดเงินและรายละเอียดทุกครั้งก่อนส่งออกภายนอก
